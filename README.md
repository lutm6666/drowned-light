# 溺光 Drowned Light

克蘇魯風格的 roguelite 動作遊戲，直接在瀏覽器裡玩。

**馬上玩：** https://lutm6666.github.io/drowned-light/

霧港燈塔的光熄了。你是守燈人，提著最後一盞燈走進地窖，一層一層往下，直到找到潮母。

## 玩法

- **魂系戰鬥**：攻擊和翻滾都消耗體力。敵人出手前有預警，翻滾有無敵時間。喝燈油回血需要時間，而且次數有限。
- **死亡與迴響**：死亡時，身上的迴響一半帶回燈塔，一半遺落在那一層。下次走到同一層可以撿回來，在那之前再死一次就會消失。
- **Roguelite**：每次下潛的地圖都重新生成。每下一層可以從三件遺物裡挑一件。迴響可以在燈塔換成永久強化。
- **理智**：理智會持續流失。低於四成時幻影會出現，歸零後開始掉血。但每一層謎題的答案，只有理智低於一半才看得見。
- **解謎與劇情**：每一層有三根石柱，要照正確順序觸碰。解開後得到一頁守燈日誌。集滿六頁再擊敗潮母，結局會多一個選擇。

## 操作

| 動作 | 鍵盤／滑鼠 |
|---|---|
| 移動 | W A S D 或方向鍵 |
| 輕攻擊 | 滑鼠左鍵 或 J |
| 重攻擊 | 滑鼠右鍵 或 K |
| 翻滾 | 空白鍵 |
| 喝燈油 | Q |
| 調查 | E |

手機或平板：左半邊拖曳移動，右下角是動作按鈕。

## 開發

整個遊戲在 `game.html` 一個檔案裡，沒有外部相依套件，圖像全部用程式畫出來。

```bash
node tools/build.js        # 由 game.html 產生 index.html
node tools/smoke-test.js   # 不開瀏覽器，跑完整個遊戲流程的測試
node serve.js              # 本機預覽 http://localhost:8123
```

修改 `game.html` 之後要重新執行 `build.js`，`index.html` 才會更新。
